# ReadmitAI - Hospital Readmission Risk Predictor

Educational Machine Learning project for predicting recorded 30-day hospital readmission among diabetic hospital encounters.

## Dataset
Diabetes 130-US Hospitals for Years 1999-2008.
Source: UCI Machine Learning Repository.
Kaggle: https://www.kaggle.com/brandao/diabetes

## Models
- Logistic Regression
- Random Forest
- XGBoost
- CatBoost

## Technology
Python, Pandas, NumPy, Scikit-learn, XGBoost, CatBoost and Streamlit.

## Features
- Project Dashboard
- Patient Prediction
- Compare All Models
- Model Analytics
- Performance Visualizations

## Run Locally
pip install -r requirements.txt
streamlit run app.py

## Disclaimer
Educational prototype only. Predictions are not medical advice or clinically validated assessments.
